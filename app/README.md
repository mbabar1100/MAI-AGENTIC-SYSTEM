# COPD Multi-Model Analysis System using Agentic AI

An intelligent AI-powered COPD analysis system developed using FastAPI and Streamlit.

## Features

- Multi-model COPD risk analysis
- Agentic AI workflow
- Streamlit frontend
- FastAPI backend
- Report generation
- Email reporting
- Visualization dashboard

## Technologies

- Python
- FastAPI
- Streamlit
- Pandas
- ReportLab
- openpyxl

## Run Backend

```bash
uvicorn app.main:app --reload
```

## Run Frontend

```bash
streamlit run ui/app.py
```
